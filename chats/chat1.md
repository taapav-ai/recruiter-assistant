# HR-панель рекрутера

_Started 2026-07-08 16:00 UTC_

---

## User

Создай веб-приложение — панель HR-инструментов рекрутера, объединяющую два модуля: «Генератор обратной связи кандидатам» и «Recruiter Assistant». Стиль: чистый, профессиональный, современный HR-tech продукт (референс — Notion/Linear), светлая тема с акцентным цветом индиго/фиолетовый (#6366F1), много воздуха, скруглённые карточки, мягкие тени.
Общая структура

Слева — боковая навигация с двумя разделами: «Фидбек для кандидатов» и «Recruiter Assistant», плюс лого/название сверху.
Справа — рабочая область, которая меняется в зависимости от выбранного раздела.

Модуль 1: Генератор обратной связи кандидатам
Цель: помочь рекрутеру быстро сформировать корректный, юридически безопасный отказ кандидату.
Экран должен содержать:

Форму ввода:

Имя кандидата
Вакансия
Этап, на котором произошёл отказ (селектор: резюме / скрининг / тестовое / интервью / финал)
Причина отказа (текстовое поле, свободный ввод рекрутера)
Тон фидбека (селектор: нейтральный / тёплый / краткий)
Язык (RU / EN / UA)


Кнопку «Сгенерировать фидбек»
Блок результата справа или снизу:

Сгенерированный текст сообщения кандидату
Индикатор «✅ Проверено на юридические риски» (без дискриминационных формулировок, без конкретики по внутренним причинам)
Кнопки: «Скопировать», «Перегенерировать», «Отправить в ATS» (декоративная кнопка-заглушка)


Историю последних 5 сгенерированных фидбеков внизу в виде списка карточек (кандидат, вакансия, дата)

Модуль 2: Recruiter Assistant
Цель: досье кандидата с загрузкой резюме и структурированным анализом.
Экран должен содержать:

Зону загрузки PDF-резюме (drag & drop, с иконкой)
После «загрузки» — карточку-досье кандидата с полями:

Имя, текущая позиция, опыт (лет)
Ключевые навыки (теги)
Краткое summary (2-3 предложения)
Оценка соответствия вакансии (прогресс-бар или процент)
Плюсы / зоны риска (два коротких списка)


Панель с вакансией, под которую идёт оценка (селектор вакансии)
Блок «Вопросы для интервью» — 5 сгенерированных вопросов под конкретного кандидата
Список ранее загруженных кандидатов слева в виде мини-карточек с фото-плейсхолдером, именем и статусом (score)

Технические требования

Адаптивный дизайн (desktop-first, но с корректным отображением на планшете)
Используй заглушечные (mock) данные для демонстрации — 2-3 примера кандидатов, готовый пример фидбека
Все интерактивные элементы (кнопки, селекторы, drag&drop) должны реально работать в интерфейсе (переключать состояния, показывать sample-результат), но без реальных API-вызовов
Цветовая палитра: фон #F8F9FC, карточки белые, акцент #6366F1, текст #1E1E2E, вторичный текст #6B7280, успех #10B981, предупреждение #F59E0B
